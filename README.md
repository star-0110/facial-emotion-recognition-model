# Facial Emotion Recognition (FER)

A computer vision model that recognizes human emotions from facial expressions.

## Overview

This project uses computer vision and deep learning to detect faces in images or video and classify the emotion each face is showing.

## What It Does

- Detects faces in an input image or video frame
- Analyzes the facial expression
- Predicts the emotion shown

## How It Works

1. A face is located in the input.
2. The face region is preprocessed.
3. The model classifies the expression into an emotion category.
   
## Limitations

- Performance can vary with lighting, image quality, occlusion, and head pose.
- Facial expressions don't always reflect how a person actually feels.
